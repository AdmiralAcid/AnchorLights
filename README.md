# Тест критического пути покупки винила в онлайн-магазине Anchor Lights

Тестирование включает в себя переход по нескольким страницам магазина, использование фильтрации по цене и цвету виниловой пластинки, использование алфавитной сортировки и выбор конкретного товара. Далее мы переходим в корзину, заполняем регистрационные данные, выбираем доставку и проверяем итоговую цену по всем слагаемым. Здесь тест заканчивается, кроме этого мы находим кнопку оформления заказа и НЕ НАЖИМАЕМ её, поскольку мы имеем дело с реальным сайтом и бизнесом, и не хотим навредить.  

base_class.py - базовый класс  
test_product_selection.py - тест  
cart_chkout_page.py - содержит имплементацию класса Checkout (нужен для работы со страницами корзины и оформления заказа)  
filters.py - содержит имплементацию класса Filter (нужен для работы с фильтрами и сортировками)  
initial.py - содержит имплементацию класса Initial (инициализация теста)  
main_page.py - содержит имплементацию класса MainPage (нужен для работы с главной страницей)  
production_page.py - содержит имплементацию класса ProductPage (нужен для работы со страницами товаров)
